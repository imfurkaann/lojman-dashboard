# Agent Documentation Index

Bu klasor, lojman-dashboard kod tabanini hata ayiklama ve bug cozum odakli anlamak icin hazirlandi.

## Dosyalar
- architecture.md: Sistem akislari, katmanlar, kritik bagimliliklar
- routes.md: Route katalogu ve sorumluluk matrisi
- database.md: SQLite semasi, migration davranisi, riskler
- bug-hotspots.md: Oncelikli hata noktalarinin listesi
- troubleshooting.md: Local ve Docker hata ayiklama adimlari
- debug-workflows.md: Tekrarlanabilir bug cozum akislari

## Hizli Baslangic (Ajanlar Icin)
1. Once architecture.md oku ve etkilenen katmani sec.
2. routes.md ile endpoint seviyesinde akis cikar.
3. database.md ile SQL/migration etkisini kontrol et.
4. bug-hotspots.md icinden benzer semptomu eslestir.
5. troubleshooting.md ile ortama gore dogrulama yap.

## Scope
- Bu dokuman seti mevcut kodun analizidir.
- Yeni ozellik tasarimi degil, mevcut davranisin cozumu hedeflenir.
